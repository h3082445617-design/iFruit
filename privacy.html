iFruit Privacy Policy

Effective date: 20 September 2026

iFruit is an offline fruit-plant library published by We The Fruit. This policy explains how the Android and desktop editions handle information.

What the app stores

The plant library is bundled in the app. It is not fetched from our servers at runtime.

If you create a local profile, the email you enter, a salted password hash, and saved taxa are stored on this device. We do not receive this information. Your operating system may include local app data in device backups, subject to your device and backup settings.

What we do not collect

This edition does not include analytics, advertising, crash telemetry, or a public export function. We do not operate a cloud account server in this edition.

Update checks

Android installs obtained directly as an APK check the public iFruit GitHub Releases API when the app opens and periodically when a network is available. Desktop editions check the same public API on startup and daily while open. The app reads only the latest release version, available platform files, and its official release-page URL. It does not send your profile, saved taxa, search history, or library data. GitHub may receive standard connection information such as an IP address and user agent under its own privacy policy. On Android 13 and later, you may deny notification permission; the offline library continues to work. Update notices open the official release page so you can choose whether to download and install. Google Play installs use Play's update system instead. No edition silently installs updates.

Your choices and deletion

You can use the library without creating a local profile. To remove local profiles, saved taxa, and other app state, clear iFruit application data or uninstall the app. You can control application backup in your operating system or account settings.

Children

iFruit is a general reference library and is not designed to collect personal information from children. Local profile information is not sent to us.
