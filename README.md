# iFruit

iFruit is an offline Android reference library for fruits and edible plants, published by We The Fruit.

The app includes country-level distribution exploration, searchable plant dossiers, source tracing and locally saved taxa. It currently contains 11 source collections, 11,483 original records and 6,633 original scientific Name values.

## Download

Download the latest signed Android APK from [Releases](../../releases/latest). Google Play testing is distributed separately through Google Play.

## Privacy

Read the [iFruit Privacy Policy](https://h3082445617-design.github.io/iFruit/privacy.html).

## Scope

- Android 10 or later
- Offline library
- No analytics or advertising
- No public data export
- Local profiles only; no live multi-device cloud sync
- Not medical or dietary advice

This repository distributes official compiled releases and public documentation. Application source code and signing material are not published here.
